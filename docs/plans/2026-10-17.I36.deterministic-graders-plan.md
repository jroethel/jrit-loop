# Deterministic Graders Implementation Plan

> For executors: tasks use checkbox syntax; execute in dependency order; a task is done when its
> acceptance check passes. No specific tooling, harness, or skills are assumed.

**Goal:** Replace the five original `llm` graders in `evals/` with `regex` graders over the same fixtures, prove every `regex` grader bites with a static test wired into CI, and record the one judge that stays.
**Approach:** Labeled probe lines added to two prompt bodies (above `## Expected behavior`) turn "paste the output" asks into lines a regex can anchor, a `count:1` grader checks the Rubix offer after its sentence is pinned word for word, and anchored `contains` / `not_contains` patterns over the emitted file check the two file-target cases.
A new `tests/eval-graders-bite.sh` mirrors the runner's verified regex semantics, runs every `regex` grader against a committed pass sample and fail sample with no model call, and later also enforces that every surviving `llm` grader is listed with a reason.
Each converted case gets one real source run to build its samples from, then must pass two of two counted eval runs at threshold 1.0.
**Tech stack:** bash, node (JavaScript `RegExp`, run from the bite test), jq (sample extraction and evidence), the Claude Code eval runner (`claude plugin eval`, 2.1.294), GitHub Actions.
**Source brief:** `docs/briefs/2026-10-17.I36.deterministic-graders-brief.md` (tracker issue #36).
**Plan review:** none was written; the decisions below were settled with the human in conversation and are the decision log.
**Rubix review:** run on 2026-10-17; findings R1-R17 were triaged and R1-R14 applied by the human's choice; the three not taken are recorded under Decisions as rejected.

## Global constraints

- Never edit any line from `## Expected behavior` to the end of file in any `evals/*/prompt.md` (criterion 2); prompt edits go only above that heading.
- Every new grader's `pattern` is a YAML double-quoted string whose escapes are JSON-compatible (`\\` for a regex backslash, `\"` for a quote), because the bite test parses double-quoted values with `JSON.parse` and rejects single-quoted ones.
- Every new grader states `match:` explicitly, and its `flags` stay within `dgimsuvy`.
- A "pass sample" is text on which the grader passes and a "fail sample" is text on which it fails; for a `not_contains` grader the pass sample lacks the pattern and the fail sample holds it.
- A fail sample is a near miss of its pass sample (one planted violation), not empty text.
- Never loosen a pattern to make a run pass if the loosened pattern no longer fails its fail sample; the D7 one-fix rule and STOP apply.
- The skill edit is exactly one wording pin in `skills/loop-plan/SKILL.md:233`; no other skill text changes and the plugin version in `.claude-plugin/plugin.json` stays `0.4.0`.
- Commit messages are plain, `<imperative summary> (Refs #36)`, with no co-author or other trailer.
- Never commit anything under `evals/results/` (it is gitignored); eval results reach the task's evidence as pasted `jq` output, because worktrees and their result files get cleaned up (R10).
- Human-read deliverables (this plan, `docs/eval-fixtures-are-engine-neutral.md`) use no em dash character, one full sentence per physical line, and aligned pipe tables; machine-read artifacts (grader files, sample `.txt` files, eval result JSONs) are exempt.

## How to run

All commands run from the repository root.

```bash
node --version                       # must print v18 or later; the bite test uses String.prototype.match and modern RegExp flags
jq --version                         # sample extraction and evidence
command -v bwrap socat               # the eval runner's sandbox backend; both paths must print
bash tests/eval-graders-bite.sh      # the static bite test (Task 1 creates it)
bash ci/run-all.sh                   # the dev gate; Task 1 wires the bite test into it
claude plugin eval . --trust-plugin --ablation none --threshold 1.0 --runs 1 --no-publish \
  --case <case> --json evals/results/I36-<case>-run<k>.json
jq -e '.aggregates.casesPassed == 1 and .aggregates.overallScore == 1' evals/results/I36-<case>-run<k>.json
jq -c '.aggregates' evals/results/I36-<case>-run<k>.json
jq -c '.cases[].arms.with[].graders[] | {name, passed, explanation}' evals/results/I36-<case>-run<k>.json
RES="$(dirname "$(git rev-parse --path-format=absolute --git-common-dir)")/evals/results"
```

The eval runner refuses every case that grants `Bash` unless a sandbox backend is installed (`docs/eval-fixtures-are-engine-neutral.md`, "Three more facts the sandbox forced"); if `command -v bwrap socat` prints fewer than two paths, install the missing one (that doc's record used `brew install socat` in a user-scope linuxbrew prefix) or put the prefix's `bin` directory on `PATH`.
The eval command exits 1 when any case scores below the threshold; the `jq -e` line prints `true` and exits 0 on a passing run.
`evals/results/` is gitignored, so result JSONs never enter a commit; the two `jq -c` lines are what goes into a task's evidence for every run.
`RES` is the main checkout's gitignored results directory, which holds earlier real outputs used only as a fallback sample source.

**Interfaces:**
- Produces: `bash tests/eval-graders-bite.sh`, run from anywhere (it `cd`s to the repo root).
  - It reads every `evals/*/graders/*.md`; frontmatter is the text between the first two `---` lines, and only top-level `key: value` lines are read.
  - A value starting with `"` is parsed with `JSON.parse` (a parse error is a `FAIL` naming the grader and key), a value starting with `'` is a `FAIL` (`single-quoted values unsupported; use double quotes`), and any other value is taken raw.

- [ ] Step 2: Write the failing test, `tests/eval-graders-bite.sh`, verbatim:

````bash
#!/usr/bin/env bash
# tests/eval-graders-bite.sh - static proof that every regex grader under
# evals/*/graders/ bites: it passes a committed good sample and fails a
# committed bad sample, with no model call (#36 criterion 3).
# Samples live at tests/fixtures/eval-graders/<case>/<grader>.pass.txt and
# .fail.txt; a sample with no matching regex grader is an orphan and fails.
# Runner semantics mirrored here, verified 2026-10-17 against the regex grader
# in the shipped claude 2.1.294 binary: new RegExp(pattern, flags); match
# defaults to contains; contains and not_contains use .test without g; count:N
# adds g and counts String.prototype.match results; flags must match
# ^[dgimsuvy]*$; a {source: file} target whose file is missing fails the grader.
# Pattern, flags, and match values must be bare or YAML double-quoted
# (parsed with JSON.parse); single-quoted values are rejected.
# The node block also prints one "llm: <path>" line per llm grader.
set -uo pipefail
fail() { echo "FAIL: $1" >&2; exit 1; }
cd "$(dirname "${BASH_SOURCE[0]}")/.." || fail "cannot reach the repo root"
command -v node >/dev/null 2>&1 || fail "node is not on PATH"
out="$(mktemp)" || fail "cannot create a temp file"
trap 'rm -f "$out"' EXIT

node - >"$out" <<'JS'
const fs = require('fs'), path = require('path');
const FIX = 'tests/fixtures/eval-graders';
const regexGraders = new Set();
let n = 0, bad = 0;
const err = (m) => { console.error('FAIL: ' + m); bad++; };
for (const c of fs.readdirSync('evals').sort()) {
  const gd = path.join('evals', c, 'graders');
  if (!fs.existsSync(gd)) continue;
  for (const g of fs.readdirSync(gd).filter((f) => f.endsWith('.md')).sort()) {
    const name = c + '/' + g.replace(/\.md$/, '');
    const fm = (fs.readFileSync(path.join(gd, g), 'utf8').match(/^---\n([\s\S]*?)\n---/) || [])[1] || '';
    const field = (k) => {
      const m = fm.match(new RegExp('^' + k + ':[ \\t]*(.*)$', 'm'));
      if (!m) return undefined;
      const v = m[1].trim();
      if (v.startsWith("'")) throw new Error(k + ': single-quoted values unsupported; use double quotes');
      if (!v.startsWith('"')) return v;
      try { return JSON.parse(v); } catch (e) { throw new Error('cannot parse ' + k + ': ' + e.message); }
    };
    let type, pattern, flags, match;
    try { type = field('type'); } catch (e) { err(name + ': ' + e.message); continue; }
    if (type === 'llm') { console.log('llm: ' + path.join(gd, g)); continue; }
    if (type !== 'regex') continue;
    regexGraders.add(name);
    n++;
    try { pattern = field('pattern'); flags = field('flags') || ''; match = field('match') || 'contains'; }
    catch (e) { err(name + ': ' + e.message); continue; }
    if (pattern === undefined) { err(name + ': no pattern in frontmatter'); continue; }
    if (!/^[dgimsuvy]*$/.test(flags)) { err(name + ': flags "' + flags + '" are outside [dgimsuvy]'); continue; }
    const count = /^count:(\d+)$/.exec(match);
    if (!['contains', 'not_contains'].includes(match) && !count) { err(name + ': unknown match ' + match); continue; }
    let re, reG;
    try { re = new RegExp(pattern, flags); reG = new RegExp(pattern, flags.includes('g') ? flags : flags + 'g'); }
    catch (e) { err(name + ': invalid pattern: ' + e.message); continue; }
    const passes = (text) => count ? (text.match(reG) || []).length === Number(count[1]) : re.test(text) === (match === 'contains');
    let ok = true;
    for (const kind of ['pass', 'fail']) {
      const f = path.join(FIX, c, g.replace(/\.md$/, '') + '.' + kind + '.txt');
      if (!fs.existsSync(f)) { err(name + ': missing sample ' + f); ok = false; continue; }
      if (passes(fs.readFileSync(f, 'utf8')) !== (kind === 'pass')) { err(name + ': the grader ' + (kind === 'pass' ? 'fails its pass' : 'passes its fail') + ' sample ' + f); ok = false; }
    }
    if (ok) console.log('ok: ' + name);
  }
}
if (fs.existsSync(FIX)) {
  for (const c of fs.readdirSync(FIX).sort()) {
    const cd = path.join(FIX, c);
    for (const s of fs.statSync(cd).isDirectory() ? fs.readdirSync(cd).sort() : ['']) {
      const m = /^(.+)\.(pass|fail)\.txt$/.exec(s);
      if (!m || !regexGraders.has(c + '/' + m[1])) err('orphan sample ' + path.join(cd, s) + ': no regex grader evals/' + c + '/graders/' + (m ? m[1] : s) + '.md');
    }
  }
}
if (n === 0) err('no regex graders found under evals/*/graders/');
if (bad) process.exit(1);
console.log('PASS: ' + n + ' regex graders bite');
JS
rc=$?
cat "$out"
[ "$rc" = 0 ] || exit 1
````
