## Approach

The chosen approach ranks work by bottleneck and deletion first, following the correction ladder in `skill-stack-proposal.md`.
A correction seen in 2 or more sessions becomes a check if it is binary, a budgeted core line if it is broad judgment, or a skill if it has a narrow trigger.
Anything else is deleted.
The rejected approach ranked by smallest diff, which put a feature (the quota tie-break) ahead of defects that cost tokens every session.

Ranked order:
1. Build the replay pack and record a baseline.
2. Fix the OPINIONS import and remove one copy of the duplicate craft skills.
3. Extend the jrit-core banned-token check into a house-style hook for written markdown, reusing `ci/banned-tokens.txt` as the single list.
4. Add the quota runway to loop-drive's Step 0 pre-flight.
5. Consolidate the self-test into one home and set a word budget for the core, keeping the cut only if the replay pack holds.
   This overlaps `2026-09-24.loop-molt-harness-evidence-brief.md`, whose end artifact is a molt run on the same three files, so step 5 should run through that work rather than beside it.

## Success criteria

- [executed-check] The skill listing contains each of craft-build, craft-write, craft-surprise, and craft-surprise-to-brand exactly once.
- [executed-check] `test -f ~/.config/jjr/OPINIONS.md`, or the import line is gone from CLAUDE.md.
- [executed-check] The house-style hook exits nonzero on a fixture file containing an em dash, and exits zero on a clean fixture.
- [executed-check] A loop-drive pre-flight on this host prints the Claude runway line from `quota-axi`.
- [executed-check] The replay pack's baseline score is recorded in a file, and step 5 records a second score.
- [judgment] Step 5's cut is kept only if Jeremy judges the replay results no worse than the baseline.

## Seams (blast-radius order)

1. Replay pack. Every later cut is judged against it.
2. Import fix and skill dedupe. These are independent and reversible.
3. House-style hook.
4. Quota runway pre-flight.
5. Core consolidation, gated on seam 1.

## Known vs guessed

- Verified: every row in the Findings table was measured on this host in the source session.
- Believed but unchecked: Claude Code's skill-catalog budget. The 8,000-char figure is OpenAI's documented Codex budget, so catalog pressure in Claude Code is inferred.
