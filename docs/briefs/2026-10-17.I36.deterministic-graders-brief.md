Tracker: jroethel/jrit-loop#36 (Refs #36).

Home: jrit-loop.
Stage: brief for /loop-plan, written as the subject of the jrit-core #45 smoke chain on jrit-loop, the chain that proves the GitHub CI watch.

## Outcome

The eval suite is a gate again: every grader that a deterministic form can express is a `regex`, `file_exists`, `tool_used`, or `tool_order` grader, and an `llm` grader survives only where judgement is the thing under test, with its reason written down.
Today six `llm` graders remain across ten cases, five from the original suite and one that arrived with #40 on 2026-10-17, and every instability the suite has ever shown came from one of the original five: #36 records four, and the #45 drive journal records a fifth on 2026-10-17, where `committed-not-uncommitted` failed 2 of 3 runs on an untouched baseline and 4 of 6 on a landed commit while every deterministic grader beside it passed every time.
Presupposition check: #36 names the fix and it is right-sized as named; the outcome is the guarantee that a red suite means a red skill, not a noisy judge.

## End artifact

The smoke chain's own measurement belongs to #45; this brief only has to be a real, small, checkable change for it to carry.

## Approach

Chosen: convert the five original `llm` graders to deterministic graders over the same fixtures, add a static bite test for every regex grader, and record any judge that must stay; the #40 judge is recorded in the table as kept and left to its own issue.
Today's reading is that none of the five needs a judge: `committed-not-uncommitted` and `docs-only-no-executables` assert a committed file and an empty command output, which labeled probe lines in the pasted output make regex-checkable; `one-offer-made` asserts a sentence said exactly once, which `count:1` on the offer sentence checks; `no-ringer-evidence` and `plan-still-delivered` assert the presence and absence of named tokens in a document, which `contains` and `not_contains` patterns check.
A labeled probe line is a prompt-body addition such as `executables=<count>` pasted beside the output it summarises; it never edits the `## Expected behavior` section, because that section is the engine-neutral contract.
Considered and declined: keeping the judges and raising the vote count (the noise is in the judge, not the vote); regrading on the trace instead of the reply (the reply is what the fixture names); a new grader type (the runner's four deterministic types cover every assertion here).
The plan may keep at most one `llm` grader, with its reason in the table, if a conversion would change what the fixture asserts.
Rationale at decision time: the smallest change that makes an 8-of-8 run at threshold 1.0 mean something, built so the smoke chain carries a wave-2 unit that depends on wave 1's bite test.

## Success criteria

1. `grep -l '^type: llm' evals/*/graders/*.md` prints only paths that appear in the "Kept llm graders" table of `docs/eval-fixtures-are-engine-neutral.md`, and the table carries one reason per row; an empty result and an empty table both pass. `[executed-check]`
2. For every `evals/*/prompt.md`, the text from the line `## Expected behavior` to the end of the file is byte-identical to the same text at the chain's merge-base commit. `[executed-check]`
3. `tests/eval-graders-bite.sh` reads every regex grader's `pattern`, `flags`, and `match` from its frontmatter, runs them against `tests/fixtures/eval-graders/<case>/<grader>.pass.txt` and `.fail.txt`, and exits 0 only when every pass sample matches and every fail sample does not; it is wired into `bash ci/run-all.sh`, and a planted sample swap makes it exit 1 in the unit's evidence. `[executed-check]`
4. Each converted case passes two of two runs of `claude plugin eval . --trust-plugin --ablation none --threshold 1.0 --runs 1 --no-publish --case <case>`, with the result JSONs copied into the unit's evidence. `[executed-check]`
5. `bash ci/run-all.sh` exits 0 on the merged tree, and GitHub CI is green on the pushed commit, which the smoke chain's CI watch proves. `[executed-check]`
